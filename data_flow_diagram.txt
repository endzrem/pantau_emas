HOW TO ADD NEW SOURCE (e.g., emasku.co.id):
═══════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  STEP 1: Create scraper method in scraper.py                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ def scrape_emasku(self):                                │   │
│  │     url = "https://www.emasku.co.id/en/gold-price"      │   │
│  │     # Fetch and parse HTML                              │   │
│  │     # Extract price                                      │   │
│  │     return {                                             │   │
│  │         'price': price,                                  │   │
│  │         'source': 'emasku.co.id',                        │   │
│  │         'currency': 'IDR',                               │   │
│  │         'unit': 'gram'                                   │   │
│  │     }                                                    │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  STEP 2: Add to get_current_price() method                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ def get_current_price(self):                            │   │
│  │     price_data = self.scrape_emasku()  # ← Add this    │   │
│  │     if not price_data:                                  │   │
│  │         price_data = self.scrape_goldprice_org()        │   │
│  │     if not price_data:                                  │   │
│  │         price_data = self.scrape_investing_com()        │   │
│  │     if not price_data:                                  │   │
│  │         price_data = self.get_mock_price()              │   │
│  │     return price_data                                   │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  STEP 3: Test it                                                │
│  $ python scraper.py                                            │
│                                                                 │
│  Output should show:                                            │
│  {                                                              │
│    "price": 950000.0,                                           │
│    "source": "emasku.co.id",                                    │
│    ...                                                          │
│  }                                                              │
└─────────────────────────────────────────────────────────────────┘
